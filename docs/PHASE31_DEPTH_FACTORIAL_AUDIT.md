# Phase31 controlled C / C-prime × MCTS depth audit

## Motivation

Phase31 C (Phase29 State V) beat C-prime (Phase31 fine-tuned State V)
55-9 in 64 complete paired matches. Prior same-board analyses
identified seven different Macro decisions from 16 C-winning-game boards.
In the seven physical outcomes, C caused 0 fouls and C-prime 3 scratches.
On three scratch boards, C-prime at depth=1 avoided two scratches
which C-prime at depth=2 chose.

That does NOT show deeper MCTS is generally worse. We first cross
C versus C-prime with depths 1 and 2 on exactly the same boards.

This evaluates 2 State V models × 2 MCTS maximum physical-shot depths.
The Macro Policy, Micro actor, physics, rack states and
simulation budget are fixed. The old depth=2 search and C-prime
original shot and rule log are checked for reproducibility.
Any invalid board is excluded from all four-condition comparisons.

## Planned follow-up: one independent question at a time

1. MCTS correctness: search-tree selection, fresh leaves, backup sign
   when players alternate, cue placement after foul, match-boundary
   accounting, final action visit/Q tie breaks. Confirm deterministic
   unit cases before changing the search itself.
2. State V / rewards: terminal match result regression is sparse
   and predicts policy-dependent MC returns. Test common held-out
   board evaluation, ranking and calibration on search-generated
   states, and mixing past/recent trajectories. Do not silently
   replace the match goal with an arbitrary foul penalty.
3. Position Attack: currently generated by trying 9 fixed
   geometrically anchored physical probe shots per pocket to
   witness a cue stop, then asking a separately trained Micro
   actor to reach that cue stop. The witnessed shot is not executed,
   so reachability does not prove the actor can achieve it.
   Evaluate Micro's actual legal-pot-and-cue-stop success before
   changing the goal generator.
4. Micro: the 5D SAC action conditioned on 72D rack + 36D goal
   should be assessed on per-goal shot accuracy, not only aggregate
   match wins. Consider local search around Micro proposals.
5. Scaling: increase State V/actor capacity or MCTS search
   depth only after evidence identifies those as bottlenecks.

Chen & Li, Macro and Micro Reinforcement Learning for Playing Nine-ball
Pool (IEEE Conference on Games, 2019; DOI 10.1109/CIG.2019.8848113)
uses macro aiming paths and 5D continuous micro control with
search-based Micro exploration and regression to high-valued shots.
This is a meaningful reference for controlled local search around
Micro proposals, not a justification for immediate SAC replacement.
Original source: https://ieee-cog.org/2019/papers/paper_162.pdf

## Limitations

This seven-board sample was drawn from C-winning games where C-prime
acted and C/C-prime disagreed. It is failure-focused, not a population
estimate or direct proof of the cause of the 55-9 result.
Do not deploy depth=1 purely from these diagnostics. A predeclared
fix would need a separate, held-out paired game evaluation.
