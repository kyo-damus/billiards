# ゼミ用・Phase 5進捗まとめ：MCTSの同点解消と実験結果

**日付:** 2026-11-10（JST）  
**対象ブランチ:** `phase10-rollout-analysis-20261110`  
**位置づけ:** リファクタリング（Phase 1〜4）に続く小規模な研究実装。今週はここで追加実装を止め、ゼミ発表準備へ移る。

## 前回からの差分

- **基盤:** Macro/Microの既存仕様を保ったまま、共通学習処理の`src/pipelines/`分離、テストの分類、FastFiz/CMakeの整理、過去モデルと生成物の保全を実施。
- **分析:** 保存済みMixed Rolloutの戦術候補・選択、各rootの訪問数と同点率、初手ポケット成功、ゲームスコア・スクラッチ、seed対応の差分をread-onlyで集計するCLIを追加。
- **MCTS:** 最終行動は「個別候補の最大visit数」を優先。従来は同点時に候補登録順の先頭を選んだ。オプション`--root-tie-breaker empirical_q`は、同点・訪問済み候補だけ`r + gamma * turn_sign * child.value`によって比較する（なお同点ならPolicy prior、登録順）。**旧`first`がデフォルト**。

## seed対応の比較実験

同じ24初期seed（95000〜95023）でMCTS探索10/50回×同点処理2方式を比較した。最大8ターン、同じ既存Micro Base/Residual・Candidate Policy/Qチェックポイント。計96ゲームRollout、CPU、追加学習なし。両方式間の同じseed初手rootでは、候補行列とvisit配列が一致していた。

| 指標 | 10回 first | 10回 empirical_q | 50回 first | 50回 empirical_q |
|---|---:|---:|---:|---:|
| **初手目標ポケットへの入球** | 12/24 | **24/24** | 24/24 | 24/24 |
| 初手Macro局所報酬平均 | 0.620 | **1.362** | 1.349 | 1.349 |
| **初手root最大visit同点数** | **24/24** | **24/24** | **4/24** | **4/24** |
| 簡易ゲーム終端件数 | 16/24 | 22/24 | 21/24 | 21/24 |
| プレイヤー0平均スコア増分 | 0.833 | 1.875 | 1.875 | 1.875 |
| 全Rolloutのスクラッチ | 3 | 0 | 0 | 0 |

同一seedの初手行動が方式間で変わったのは、探索10回で23/24、50回で2/24。探索10回では訪問数同点の処理方法が行動選択に大きく影響した。探索50回では同点が減少し、主要指標はほぼ一致した。

## 研究上の注意点と限界

1. **戦術の均等化は行っていない。** DIRECT/POSITION/SAFETYの選択数は診断用。DIRECTが最も高い観測QならDIRECTが選ばれてよい。戦術の選択割合を目標にする調整はしない。
2. **報酬設計の影響が残る。** `src/macro/local_evaluation.py` の既定値は、目標入球+1、wrong-pocket −0.5、scratch −1、条件を満たすPOSITION配置に品質×0.5、次ショットが可能なら+0.25。POSITIONに追加報酬があるため、局所報酬の上昇だけでゲーム全体の最適性を主張しない。
3. **終端件数は勝利数ではない。** 簡易2的球ルールでスクラッチもゲーム終了に含まれ、8ターン打ち切りもある。
4. 24初期seed・同一Micro/物理・訓練データとの独立性未確認。50回探索では初手成功24/24の天井効果がある。
5. 全ターンroot同点率は10回first=59/114、10回empirical_q=46/61、50回はいずれも4/66。ただし10回条件の2方式は途中から軌跡が異なるため、**全ターン同点率は同一盤面集団の対比較ではない**。
6. DGXで既存の比較・分析テスト26件がPASSED（2.86秒）、探索関連31件も過去にPASSED。今回の戦術非均等化の追加回帰テストは**DGXの実行結果待ち**。
